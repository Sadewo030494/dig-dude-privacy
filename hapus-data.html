Permintaan penghapusan data Dig Dude

Halaman ini untuk pemain game Dig Dude (pengembang: Geek Aura) yang ingin meminta penghapusan datanya.

Data apa yang ada?

Dig Dude tidak memiliki akun, login, atau penyimpanan data di server kami. Progres game disimpan hanya di HP-mu. Layanan pihak ketiga (Google AdMob dan Google Firebase Analytics) dapat memproses ID iklan dan data penggunaan umum, sesuai Kebijakan Privasi.

Cara menghapus data

  • Data di HP: hapus aplikasi Dig Dude, atau buka Setelan Android → Aplikasi → Dig Dude → Penyimpanan → Hapus data.
  • ID Iklan: setel ulang atau hapus di Setelan Android → Google → Iklan.
  • Permintaan lewat email: kirim email ke aurageek666@gmail.com dengan subjek "Permintaan hapus data Dig Dude". Kami memprosesnya paling lambat 30 hari.
